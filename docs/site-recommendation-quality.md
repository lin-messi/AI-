# 全站推荐质量策略

推荐先检查主题与来源，再比较时间、实现线索和公开指标。热度、会议信息、生成的中文说明不能替代适用性证据。所有数字均表示某次查询的快照，不是近期增长或效果保证。

## 新闻

- `editorial-policy.mjs` 按原始标题、原始 RSS 摘要识别 AI/机器人主题；`source_title/source_summary/source_lang` 保留来源事实，中文翻译不反向构成事实证据。
- 按实际 URL 域名标记一手发布、媒体报道、聚合入口、未归类来源。不根据新闻自报的机构名把 Google News 链接标成官方页面，不把来源类型称为事实交叉验证。
- 发布时间必须真实有效且不晚于当前时间。仅纳入近 48 小时消息；无日期不会补成今天。单域名最多占池的 18%，单分类最多 40%，总数不超过 100。数量不足时保留实际结果。
- 预印本不再重复占新闻位置，由论文栏目收集。分类采用单词边界，避免 `act` 出现在其他单词内部时误判政策。
- 翻译随原始信息量，不要求从一句标题扩写几百字。原始材料不足时明确指出，不补数字、引语或因果关系。全部近期源失败时保留上次快照和采集时间。

## 学术论文

- 六个学科和交叉方向分开查询，每组有独立的 arXiv 候选预算；按作者的首个学科分类归属，避免界面排列顺序改变论文主领域。
- 日更窗为近 120 小时，每领域最多 24 篇，同日合并后再限额。保留中文译文，同时更新真实元数据。跨领域默认排序按各领域轮换，领域内按推荐依据排序。
- Hugging Face 社区点赞最多贡献 4 个推荐分，不能当作引用或同行评审。原先的 `点赞×50` 不再决定默认顺序。手动热度排序仍可使用。
- `research-reference-catalog.json` 保存少量经过人工核对的原始论文入口与使用边界；`fetch-research-references.mjs` 核验 DOI 与标题身份并获取 Crossref 的 `is-referenced-by-count`。缓存七天，失败保留原核验时间，不以参考文献缓存冒充日更成功。
- 长期参考标记要求发表至少两年、有日期且来自允许的指标 API 的至少 100 次引用。它是检索线索，不是质量认证。没有来源摘要的论文不生成摘要或精读；日期只有年/月时明确显示精度。
- 正文摘要翻译覆盖最终展示池，精读仅覆盖精选。目录给出的作者代码单独链接；未核实代码时不声称存在实现。

## GitHub 开源

- 围绕模型、智能体、视觉、机器人、科研计算与 AI 系统分别检索近期和成熟项目。先检查项目自身名称及原始简介中的用途，owner 或 README 中提及品牌不能单独构成相关性。
- 少数简介很短的经典科学工具使用精确 owner/repo 与 GitHub URL 双重映射，不能通过相似名称冒充。
- 近期新项目要求真实创建日期不超过 90 天、真实代码推送不超过 90 天、至少 5 星及指标核验时间。成熟参考要求至少两年历史、至少 500 星及核验时间。旧项目近期有提交不称为新项目。
- 排除归档、禁用和 fork；记录许可证和维护情况。许可未识别时明确提示，不等同确认可自由复用。累计 Stars 有界加分，不当作近期增长。
- 总池 32 项，单 owner 至多 2 项，主方向最多占 28%；在有符合条件的候选时兼顾各方向与新旧两类。同日合并更新星标、推送、许可等字段，同时填补旧中文空缺。

## RoboMaster

- `rm-topic-policy.mjs` 用实际能力组合识别检测跟踪、能量机关、SLAM、地面导航、规划、全场定位、控制、视觉伺服装配、仿真与策略学习。泛 `vision`、`pose estimation`、`state estimation` 不能直接变成自瞄、装配或全场雷达。
- 原始标题和摘要主体检查应用场景；医疗、人体姿态等任务不因出现机器人或规划词就进入 RM 实用池。中文生成的用途、亮点和翻译不能创造入选证据。
- 采集、CVF 补充、同日合并与当前快照复筛使用同一能力闸门。为可用方向预留小配额，并对无人机、光通信占比设界限；不为填满数量造数据。光通信仍保留两类接收端及近期、长期参考的覆盖。
- 每项说明区分直接 RM 项目和可迁移方法，注明 2027 外观、地图、算力、传感器、协议等适配前提。长期标签需要真实历史与已查询指标，不能只靠年份或大仓库名。
- 模型用途评估只接受该项已经由能力策略支持的规则任务；不允许把通用激光里程计生成成雷达实现。没有摘要时不靠标题生成用途。通用成果不能自动获得“拿来可用”的高实用度。
- `refresh-rm-recommendations.mjs` 可从全部方向的近 90 天归档补充，支持 `--paper-library` 与 `--repo-metadata` 注入已核验元数据。复筛、翻译时间分别记录，不改真实采集时间。

## 验证与维护

`npm run test:recommendations` 覆盖不相关高星应用、品牌 owner 冒充、词内误匹配、医疗场景绕过、日期污染、证据来源、真实指标、翻译保留、同日限额、学科/任务覆盖和模型评估越界。`npm run build:cloudflare`、`npm run test:cloudflare`、`npx wrangler deploy --dry-run` 验证交付。

新闻与开源的来源数量、论文的每领域数量是候选与覆盖预算，不是对每次定时任务完整性或每条内容正确性的保证。源失败时保留证据和真实时间，缺少候选时不降低相关性门槛凑数。
